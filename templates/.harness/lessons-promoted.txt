# Promoted lesson ids (one per line).
# metrics.ps1 reads this file. Keep it tracked so every clone sees the same
# "already promoted" status.
#
# A promoted lesson must carry the check that makes it impossible to repeat:
#   lesson-id :: check=<path relative to the project root>::<what the check proves>
# The check must be a runnable .ps1/.py that contains the lesson id (a comment is
# enough, e.g. "# lesson: gate-binding-too-strict"). metrics.ps1 -LessonGate
# rejects: no check, a doc path, a directory, a missing file, or a file that
# never names the id. verify-harness and stage-gate stage 10 both call it.
#
# The id inside the check is only an audit anchor, not proof of relevance: before
# promoting, a reviewer (human, or the code-reviewer / consistency-verifier agent)
# opens the check and confirms it would actually fail on this lesson.
#
# Example:
#   gate-binding-too-strict :: check=tests/test-update.ps1::merged rows keep project names
