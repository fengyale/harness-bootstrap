# Promoted lesson ids (one per line).
# metrics.ps1 reads this file. Keep it tracked so every clone sees the same
# "already promoted" status.
#
# A promoted lesson must carry the check that makes it impossible to repeat:
#   lesson-id :: check=<path relative to the project root>::<what the check proves>
# The check file must also contain, as comments:
#   # lesson: <lesson-id>
#   # fails-when: <the change that makes this check red>
# Plain "lesson-id" lines still count as promoted, but metrics.ps1 -LessonGate
# (run by verify-harness and stage 10) rejects a repeated lesson that has no
# usable check. The fails-when line is the claim a reviewer reproduces; it is not
# proof by itself.
# Example:
#   gate-binding-too-strict :: check=tests/test-update.ps1::merged rows keep project names
#   # in tests/test-update.ps1:
#   # lesson: gate-binding-too-strict
#   # fails-when: the merge replaces a project rule name with the template cell
