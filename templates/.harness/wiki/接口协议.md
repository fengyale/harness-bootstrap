## 通用约定

### Base URL

```text
Development: <http://localhost:8080>
Production:  <https://api.example.com>
```

### 请求头

| Header | Required | Description |
| --- | --- | --- |
| `Content-Type` | Yes | `application/json` |
| `Authorization` | 需认证接口必填 | `<Bearer {token}>` |

> `<如：用户身份一律从令牌解析，接口参数不透传 userId。>`

### 统一响应格式

```json
{
  "code": 200,
  "message": "success",
  "data": {},
  "timestamp": 0
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `code` | Integer | 业务状态码 |
| `message` | String | 提示信息 |
| `data` | T | 业务数据 |
| `timestamp` | Long | 服务器时间戳（毫秒） |

### 分页响应

```json
{ "code": 200, "data": { "list": [], "total": 0, "page": 1, "size": 20 } }
```
