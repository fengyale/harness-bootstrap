# 模块卡片（modules）

> **按需加载**：定位到某个 module 后再读对应卡片；不要全量加载。
> 技能回答"这类活怎么干"，模块卡片回答"**在这个地方干会踩什么**"。

## 收录规则

- 每张卡固定八节：职责 / 关键入口 / 依赖与数据 / 重点 / 难点 / 坑点 / 验证方式 / 证据锚点（以 `_template.md` 为准）
- 每条结论必须带 `- [E2] 真实路径 :: 证明了什么`；拿不到证据的写 `TODO(待确认)`
- 只写**这个模块特有**的事实；通用规范留在 `.harness/rules/`

## 生成与更新

- **初次落地**：按 `stack.json` + 代码入口取证生成，优先 3–5 个高频模块，不是 12 个全写
- **使用中**：任务发现新坑 → 当场追加到对应卡片「坑点」，写日期与证据
- **复盘**：一个月未更新的卡片检查一次；连续两轮无更新的可以合并或删除

## 命名

`modules/<module 目录名>.md`，与 `pom.xml` 的 module 名一致。
