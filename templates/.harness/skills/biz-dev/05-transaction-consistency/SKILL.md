# 事务与一致性

> **本文件是骨架**：`<!-- slot:… -->` 必须在安装时用项目事实替换。

## 何时用

- 一次改动写多张表 / 调外部接口 / 更新缓存
- 同一请求可能重复提交或重复消费

- 幂等键的取法：<!-- slot:idempotency.key -->
- 项目特有的事务约束：<!-- slot:tx.constraints -->

## 模式（跨技术栈不变）

### 步骤

1. 圈定事务边界：哪些写必须原子
2. **找同模块既有事务写法并沿用**，不新造第三种
3. 缓存更新放在提交后
4. 外部调用移出事务（或明确补偿方案）
5. 需要幂等时用业务唯一键查重

### 检查项

- [ ] 事务边界包含全部必需写入
- [ ] 受检异常是否回滚
- [ ] 缓存与库的更新顺序正确
- [ ] 重复提交/消费有幂等键

### 常见错误

- 事务内调远程接口 → 长事务且无法回滚
- 先删缓存再提交 → 脏读
- 只包了一半写入 → 半提交
