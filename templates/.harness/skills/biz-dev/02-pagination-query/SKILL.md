# 分页查询

> **本文件是骨架**：`<!-- slot:… -->` 必须在安装时用项目事实替换，替换不到就整条删除。

## 何时用

- 新增或改造列表接口，同时要返回总数与当前页数据
- 现有分页在深页变慢，或被慢查询告警命中
- 前端反馈翻页后数据重复、缺失，或总数与实际条数不符

## 模式（跨技术栈不变）

### 步骤

1. 只写一份条件构造，统计与取数共用它，禁止各写一遍
2. 定稳定排序：至少带一个唯一键兜底，避免同序值导致跨页重复
3. 判断数据量与过滤度：小表偏移分页够用，深页改按唯一键续取
4. 核对排序与过滤字段是否有可用索引，看执行计划而非凭经验
5. 明确空结果语义：空列表、页码越界、总数不变，三者口径统一
6. 用大偏移量与极端过滤条件各压一次，记录耗时与扫描行数

### 检查项

- [ ] 统计与取数条件完全一致（含软删除、归属过滤、状态过滤）
- [ ] 排序字段组合能唯一确定一行
- [ ] 深页场景未走全量扫描，执行计划已核对
- [ ] 空结果与越界返回的结构对调用方是同一种形状
- [ ] 分页参数有上限，避免一次取全量

### 常见错误

- 统计语句漏掉取数里的过滤条件，总数长期偏大
- 用非唯一字段排序，翻页出现重复行或漏行
- 先联多表再分页，深页代价随偏移线性增长
