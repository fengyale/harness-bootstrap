# 表格导入与导出

> **本文件是骨架**：`<!-- slot:… -->` 必须在安装时用项目事实替换，替换不到就整条删除。

## 何时用

- 需要让使用者批量导入数据，且数据可能不干净
- 导出结果可达数万行以上，页面同步等待会超时
- 已有导入只回一句失败，无法定位是哪一行出错

## 模式（跨技术栈不变）

### 步骤

1. 先定模板：表头顺序、必填列、取值示例，模板带版本号
2. 流式逐行读取，禁止整份文件载入内存
3. 解析前校验表头与版本，不匹配直接整体拒绝
4. 逐行校验并记录行号、列名、原因，不抛第一个错就中断
5. 失败策略二选一并写进契约：整批回滚，或部分成功加错误报告
6. 导出分批取数、边生成边下发，设单次行数上限
7. 临时文件在成功与失败路径都清理，异常退出靠定时任务兜底

### 检查项

- [ ] 表头不符时整体拒绝，且提示缺哪一列
- [ ] 错误报告含行号、列名、原因，可直接照着改
- [ ] 导入内存占用不随行数线性增长
- [ ] 导出耗时与行数成正比，且有明确上限
- [ ] 成功与失败路径都不残留临时文件

### 常见错误

- 一次性读全表再逐行处理，大文件直接拖垮进程
- 失败只返回一句"导入失败"，使用者无从修正
- 先查全量再拼装导出，内存与耗时双双失控
