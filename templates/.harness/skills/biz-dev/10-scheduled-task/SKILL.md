# 定时任务

> **本文件是骨架**：`<!-- slot:… -->` 必须在安装时用项目事实替换，替换不到就整条删除。

## 何时用

- 新增按周期执行的批处理、同步或清理任务
- 已有任务在多实例部署后重复执行
- 任务失败无人知晓，需要可观测与补跑入口

## 模式（跨技术栈不变）

### 步骤

1. 定周期、时区、最长允许执行时长，超时要有明确处置
2. 任务自身幂等：以业务键去重，重复跑结果与跑一次相同
3. 多实例互斥：用带过期的锁或选主，异常退出不会永久阻塞
4. 失败分级：可重试按退避重试，不可重试立即告警
5. 每次执行留痕：开始、结束、处理条数、结果、异常摘要
6. 提供手动补跑入口，补跑与自动调度互斥
7. 上线后观察几轮执行时长基线，异常变慢先于失败被发现

### 检查项

- [ ] 双实例部署时同一时刻只执行一次
- [ ] 重复执行不产生重复业务数据
- [ ] 失败能在监控里看到，并指向具体批次
- [ ] 执行记录含耗时与处理条数
- [ ] 补跑不破坏幂等，也不会与调度撞车

### 常见错误

- 靠单副本部署保证唯一，一扩容就重复执行
- 捕获异常后只打日志不上报，失败静默
- 锁不设过期，进程异常退出后任务永久卡死
