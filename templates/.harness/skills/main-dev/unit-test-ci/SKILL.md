# 持续集成流水线

> **本文件是骨架**：`<!-- slot:… -->` 必须在安装时用项目事实替换，替换不到就整条删除。

## 何时用

- 新增或迁移持续集成流水线
- 流水线绿灯但线上仍出问题，门禁形同虚设
- 失败构建难以复现，日志与产物已丢失

## 项目绑定（编译时替换）

- 流水线配置位置与触发条件：<!-- slot:ci.config -->
- 覆盖率门禁的指标与阈值：<!-- slot:coverage.threshold -->
- 可本地执行的门禁命令：<!-- slot:gate.cmd -->

## 模式（跨技术栈不变）

### 步骤

1. 固定阶段顺序：拉取 → 编译 → 静态检查 → 单元测试 → 打包 → 留存制品
2. 前一阶段失败不进入下一阶段，防止产出半成品制品
3. 依赖与构建缓存按锁文件或哈希命中，避免每次全量下载
4. 覆盖率门禁只对增量或核心模块设阈值，阈值需长期可维持
5. 报告与制品定保留期，失败构建的日志必须可追溯
6. 门禁脚本与本地命令共用同一份，避免"本地过、流水线不过"
7. 定期抽查：门禁是否被绕过，通过是否来自有效断言

### 检查项

- [ ] 本地一条命令即可复现流水线门禁结果
- [ ] 阈值有具体数值，且历史上真实拦截过
- [ ] 阶段失败时不产生可发布制品
- [ ] 每次失败的日志与报告可追溯
- [ ] 流水线总耗时在团队可接受范围

### 常见错误

- 测试与打包并行，测试失败仍产出可发布制品
- 阈值靠无断言用例凑数，绿灯但无保护力
- 只保留成功构建产物，失败现场无法复盘
