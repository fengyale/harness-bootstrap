## 何时用

- 接口响应 > 1 秒

## 模式（跨技术栈不变）

### 步骤

1. 从日志/监控拿到**完整 SQL 与参数**
2. 看执行计划：访问类型、扫描行数、是否排序/临时表
3. 判断原因：缺索引 / 索引失效（函数、隐式转换、前导通配）/ 返回行过多
4. 深分页改游标或延迟关联
5. 改完对比执行计划与实际耗时

### 检查项

- [ ] 有执行计划前后对比
- [ ] 索引覆盖 where 与 order by
- [ ] 没在索引列上做函数或类型转换
- [ ] 分页不是大 offset

### 常见错误

- 只看 SQL 不看执行计划
- 加索引不看写入成本
- `select *` 拉全列
