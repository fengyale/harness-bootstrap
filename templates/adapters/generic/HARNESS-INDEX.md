# 技能索引（适用于没有技能自动发现的平台）

> **使用方式**：开始任何任务前，先按"任务类型"定位 1–2 个技能，**完整读取** `SKILL.md` 后再动手。
> 不要凭记忆执行，也不要一次加载全部技能（正文体积会挤掉项目上下文）。

| 任务类型 | 先读 | 触发词示例 |
| --- | --- | --- |
| 需求分析 / 拆解 | `main-dev/request-analysis/SKILL.md` | 加个功能、改个逻辑、做一版 |
| 写代码 / 改代码 | `main-dev/coding-skill/SKILL.md` | 实现、重构、补接口 |
| 写单元测试 | `main-dev/unit-test-write/SKILL.md` | 补测试、覆盖率 |
| 代码评审 | `main-dev/expert-reviewer/SKILL.md` | 审一下、review、能不能上 |
| 排查线上问题 | `trouble-shooting/<最接近的现象>/SKILL.md` | 慢、超时、OOM、CPU 高、积压 |
| 常见业务实现 | `biz-dev/<最接近的专题>/SKILL.md` | 缓存、分页、事务、导入导出 |
| 发布 / 验证 | `main-dev/deploy-verify/SKILL.md` | 上线、验证、回滚 |

## 维护

- 技能只装 3–5 个：上表是按需导航，不是安装清单
- 某个技能连续 28 天 0 次加载 → **列为候选**，确认场景确实不再需要后再删，并从本表移除
- 新增技能必须同时更新本表，否则在没有自动发现的平台上等于不存在
