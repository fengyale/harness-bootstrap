# patterns（跨项目模式库）

> 这里只存**技术中立的模式**，来源是 ≥2 个独立项目的同一指纹（见 `references/回灌协议.md`）。
> 与 `templates/.harness/skills/` 的分工：技能是"怎么干活"，patterns 是"为什么这么干"。

## 收录条件

- [ ] 指纹：`<栈键>|<症状码>|<id>`
- [ ] `projects >= 2`
- [ ] 含三节：`## 模式` / `## 反例` / `## 证据`
- [ ] 不含项目名、类名、包名、具体 API
- [ ] 已在包 VERSION 里登记来源

## 命名

`patterns/<栈键>-<症状码>.md`，例如 `orm-jfinal-n-plus-one.md`

## 使用方式

安装器编译技能时，优先复用这里已有的模式段，而不是重写一遍。
